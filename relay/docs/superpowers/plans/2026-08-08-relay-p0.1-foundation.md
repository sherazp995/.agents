# Relay P0.1 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Relay repository with strict TypeScript, a fail-closed configuration layer, structured logging, a migrated Postgres schema, Redis, and a `relay doctor` command that reports the truth about every dependency.

**Architecture:** A single pnpm package with focused modules under `src/`. Configuration is parsed and validated by Zod at startup and refuses to run when invalid, because a permissive default is the failure mode the spec forbids. Persistence is plain `pg` with SQL migrations applied by a small in-repo runner, so the schema is readable and reversible without an ORM. Every table carries `workspace_id` from the first migration. Nothing in this milestone talks to Slack, a model provider, or a browser.

**Tech Stack:** Node 22, pnpm 10, TypeScript strict, Vitest, Zod, Pino, `pg`, `ioredis`, Commander, Docker Compose for Postgres and Redis.

## Global Constraints

Every task's requirements implicitly include these. Values are copied verbatim from `docs/specs/2026-08-08-relay-requirements.md` v1.10.

- **AP-8:** every table carries `workspace_id` from the first migration.
- **FR-POL-2:** policy is validated on load; an invalid policy file fails closed and prevents startup, rather than defaulting permissive.
- **FR-POL-3:** the default for anything unmatched is `ask`, never `allow`.
- **FR-POL-4:** the hard-blocked origin list cannot be overridden at runtime; changing it requires a config edit plus restart.
- **FR-SET-7:** setup will not complete with an empty hard-blocked origin list.
- **FR-DATA-6:** exactly one provider is configured for the agent loop; zero data retention must be asserted in configuration; a provider misconfiguration fails closed and refuses to run.
- **FR-DATA-8:** classification is mandatory at registration; an unclassified entry cannot be used.
- **FR-OBS-1:** structured JSON logs carry run, session, step, and principal identifiers on every line, at configurable levels, rotated and size-capped.
- **FR-SEC-1:** no secret is stored in the repository, the database, the object store, or any log.
- **NFR-10:** the core carries no macOS-specific dependency.
- **NFR-11:** one stated purpose per module, documented interface, independent tests.
- **Rule 45:** no dash used as sentence punctuation in any prose, including code comments and commit messages. Hyphens inside a compound word are fine.
- **Rule 41:** cache test output to `tmp/test-cache/<name>.log`.
- **Rule 42:** purely additive diffs run only their own narrow tests.

```typescript
/**
 * Raised when a configuration file is missing, malformed, or semantically
 * invalid. Relay fails closed on any of these, per FR-POL-2. The message
 * always names the file so the operator knows where to look.
 */
export class ConfigError extends Error {
  readonly filePath: string
  readonly reason: string

  constructor(filePath: string, reason: string) {
    super(`Invalid configuration in ${filePath}: ${reason}`)
    this.name = 'ConfigError'
    this.filePath = filePath
    this.reason = reason
  }
}
```

Create `src/config/schema.ts`:

```typescript
import { z } from 'zod'

/**
 * Policy shape. Two rules are enforced here rather than at call sites,
 * because a permissive policy that merely fails later is the exact failure
 * mode FR-POL-2 forbids.
 */
export const policySchema = z.object({
  version: z.literal(1),
  defaults: z.object({
    // FR-POL-3: anything unmatched is asked, never allowed.
    unmatched: z.literal('ask'),
  }),
  // FR-SET-7: setup cannot complete with an empty hard-blocked list.
  hard_blocked_origins: z.array(z.string().min(1)).min(1),
})

export type Policy = z.infer<typeof policySchema>

export const relayConfigSchema = z.object({
  model_provider: z.object({
    name: z.enum(['anthropic']),
    // FR-DATA-6: retention must be asserted, not assumed.
    zero_data_retention: z.literal(true),
  }),
  database: z.object({ url: z.string().url() }),
  redis: z.object({ url: z.string().url() }),
  logging: z.object({
    level: z.enum(['trace', 'debug', 'info', 'warn', 'error', 'fatal']).default('info'),
  }),
})

export type RelayConfig = z.infer<typeof relayConfigSchema>
```

Create `src/config/load.ts`:

```typescript
import { readFileSync } from 'node:fs'
import { parse as parseYaml } from 'yaml'
import type { z } from 'zod'
import { ConfigError } from './errors.js'
import { type Policy, type RelayConfig, policySchema, relayConfigSchema } from './schema.js'

function loadValidated<T>(filePath: string, schema: z.ZodType<T>): T {
  let raw: string
  try {
    raw = readFileSync(filePath, 'utf8')
  } catch {
    throw new ConfigError(filePath, 'file could not be read')
  }

  let parsed: unknown
  try {
    parsed = parseYaml(raw)
  } catch (error) {
    throw new ConfigError(filePath, `YAML could not be parsed: ${(error as Error).message}`)
  }

  const result = schema.safeParse(parsed)
  if (!result.success) {
    const detail = result.error.issues
      .map((issue) => `${issue.path.join('.') || '<root>'}: ${issue.message}`)
      .join('; ')
    throw new ConfigError(filePath, detail)
  }
  return result.data
}

/** Loads and validates policy. Throws ConfigError rather than returning a partial value. */
export function loadPolicy(filePath: string): Policy {
  return loadValidated(filePath, policySchema)
}

/** Loads and validates runtime configuration. Throws ConfigError rather than returning a partial value. */
export function loadRelayConfig(filePath: string): RelayConfig {
  return loadValidated(filePath, relayConfigSchema)
}
```

```typescript
import { Writable } from 'node:stream'
import { describe, expect, it } from 'vitest'
import { createLogger, withContext } from '../../src/obs/logger.js'

function captureLines(): { stream: Writable; lines: () => unknown[] } {
  const chunks: string[] = []
  const stream = new Writable({
    write(chunk, _encoding, callback) {
      chunks.push(String(chunk))
      callback()
    },
  })
  return {
    stream,
    lines: () =>
      chunks
        .join('')
        .split('\n')
        .filter((line) => line.trim().length > 0)
        .map((line) => JSON.parse(line) as unknown),
  }
}

describe('logger', () => {
  it('emits JSON', () => {
    const { stream, lines } = captureLines()
    createLogger('info', stream).info('hello')
    expect(lines()).toHaveLength(1)
    expect(lines()[0]).toMatchObject({ msg: 'hello' })
  })

  it('binds run, session, step, and principal ids onto every line, per FR-OBS-1', () => {
    const { stream, lines } = captureLines()
    const logger = withContext(createLogger('info', stream), {
      runId: 'run_1',
      sessionId: 'ses_1',
      stepId: 'step_1',
      principalId: 'prn_1',
    })
    logger.info('first')
    logger.info('second')
    for (const line of lines()) {
      expect(line).toMatchObject({
        runId: 'run_1',
        sessionId: 'ses_1',
        stepId: 'step_1',
        principalId: 'prn_1',
      })
    }
  })

  it('honours the configured level', () => {
    const { stream, lines } = captureLines()
    createLogger('warn', stream).info('suppressed')

  })
```

```typescript
import pino, { type Logger } from 'pino'
import type { RelayConfig } from '../config/schema.js'

export type { Logger }

/**
 * Identifiers bound onto every log line so any run can be reconstructed by
 * grepping one id, per FR-OBS-1.
 */
export type LogContext = {
  runId?: string
  sessionId?: string
  stepId?: string
  principalId?: string
}

/**
 * Creates the root logger. The destination is injectable so tests can capture
 * output without touching the filesystem or stdout.
 */
export function createLogger(
  level: RelayConfig['logging']['level'],
  destination: NodeJS.WritableStream = process.stdout,
): Logger {
  return pino({ level, base: undefined }, destination)
}

/** Returns a child logger carrying the given identifiers on every line. */
export function withContext(logger: Logger, context: LogContext): Logger {
  const bindings: Record<string, string> = {}
  for (const [key, value] of Object.entries(context)) {
    if (value !== undefined) bindings[key] = value
  }
  return logger.child(bindings)
}
```

### Task 4: Postgres, migrations, and the initial schema

> **Amended after review.** The code below was implemented and then corrected, because review disproved three of its claims. The shipped implementation in `src/db/migrate.ts` and `test/db/migrate.test.ts` differs from the listings here and is authoritative. Read the shipped code, not these listings, if the two disagree. The corrections were: a session-level Postgres advisory lock held across `applyMigrations` and released in a `finally`, with the applied set re-read after the lock is acquired, because two concurrent callers otherwise crash the loser on a duplicate key; a guarded `ROLLBACK` so a rollback failure on a broken connection cannot mask the original error, plus rejection of any migration file carrying its own `BEGIN`, `COMMIT`, or `ROLLBACK`; and a guard asserting the target database name ends in `_test` before the test drops its schema.

```typescript
const url = process.env.RELAY_TEST_DATABASE_URL

describeDb('applyMigrations', () => {

  beforeAll(async () => {
    pool = createPool(url as string)
    await pool.query('DROP SCHEMA public CASCADE; CREATE SCHEMA public;')
  })

  afterAll(async () => {
    await closePool(pool)
  })

  it('applies every migration once and is idempotent on a second run', async () => {
    const first = await applyMigrations(pool, 'src/db/migrations')
    expect(first).toContain('0001_init.sql')

      FROM information_schema.tables t
      WHERE t.table_schema = 'public'
        AND t.table_type = 'BASE TABLE'
        AND t.table_name NOT IN ('schema_migrations', 'workspaces')
        AND NOT EXISTS (
          SELECT 1 FROM information_schema.columns c
          WHERE c.table_schema = 'public'
            AND c.table_name = t.table_name
            AND c.column_name = 'workspace_id'
        )

    await applyMigrations(pool, 'src/db/migrations')
```

```typescript
import { readdirSync, readFileSync } from 'node:fs'
import { join } from 'node:path'
import type { Pool } from 'pg'

/**
 * Applies pending SQL migrations in filename order, each inside its own
 * transaction together with its bookkeeping row, so a failure leaves neither
 * a half-applied schema nor a false record of success.
 *
 * Returns the migrations applied by this call. An empty array means the
 * schema was already current.
 */
export async function applyMigrations(pool: Pool, directory: string): Promise<string[]> {
  await pool.query(`
    CREATE TABLE IF NOT EXISTS schema_migrations (
      name       text PRIMARY KEY,
      applied_at timestamptz NOT NULL DEFAULT now()
    )
  `)

  const { rows } = await pool.query<{ name: string }>('SELECT name FROM schema_migrations')
  const applied = new Set(rows.map((row) => row.name))

  const pending = readdirSync(directory)
    .filter((name) => name.endsWith('.sql'))
    .sort()
    .filter((name) => !applied.has(name))

  const run: string[] = []
  for (const name of pending) {
    const sql = readFileSync(join(directory, name), 'utf8')
    const client = await pool.connect()
    try {
      await client.query('BEGIN')
      await client.query(sql)
      await client.query('INSERT INTO schema_migrations (name) VALUES ($1)', [name])
      await client.query('COMMIT')
      run.push(name)
    } catch (error) {
      await client.query('ROLLBACK')
      throw new Error(`Migration ${name} failed: ${(error as Error).message}`)
    } finally {
      client.release()
    }
  }
  return run
}
```

```typescript
export type { Redis }

/**
 * Creates the Redis client. Retries are bounded and lazy connection is off,
 * so an unreachable server surfaces quickly in `relay doctor` rather than
 * retrying forever behind a healthy-looking process.
 */
export function createRedis(url: string): Redis {
  return new Redis(url, {
    maxRetriesPerRequest: 1,
    retryStrategy: (times) => (times > 2 ? null : 100),
    lazyConnect: false,
    enableOfflineQueue: false,
  })
}

/** Closes the client. Safe to call on a client that never connected. */
export async function closeRedis(redis: Redis): Promise<void> {
  redis.disconnect()
}

/**
 * Health probe. Resolves false rather than throwing, because the caller is a
 * diagnostic that must report every check, not abort on the first failure.
 */
export async function pingRedis(redis: Redis): Promise<boolean> {
  try {
    return (await redis.ping()) === 'PONG'
  } catch {
    return false
  }
}
```

```typescript
import { loadPolicy, loadRelayConfig } from '../config/load.js'
import { closePool, createPool } from '../db/pool.js'
import { closeRedis, createRedis, pingRedis } from '../redis/client.js'

export type CheckStatus = 'ok' | 'degraded' | 'failed'

/**
 * One diagnostic result. `remediation` is present whenever the operator can
 * act, because a diagnosis without an action is just bad news.
 */
export type CheckResult = {
  name: string
  status: CheckStatus
  detail: string
  remediation?: string
}

const MINIMUM_NODE_MAJOR = 22

export function checkNodeVersion(actual: string): CheckResult {
  const major = Number.parseInt(actual.replace(/^v/, '').split('.')[0] ?? '0', 10)
  if (major >= MINIMUM_NODE_MAJOR) {
    return { name: 'node', status: 'ok', detail: actual }
  }
  return {
    name: 'node',
    status: 'failed',
    detail: `${actual} is below the minimum`,
    remediation: `Install Node ${MINIMUM_NODE_MAJOR} or newer.`,
  }
}

export function checkConfig(configPath: string, policyPath: string): CheckResult {
  try {
    loadRelayConfig(configPath)
    loadPolicy(policyPath)
    return { name: 'config', status: 'ok', detail: `${configPath}, ${policyPath}` }
  } catch (error) {
    if (error instanceof ConfigError) {
      return {
        name: 'config',
        status: 'failed',
        detail: error.reason,
        remediation: `Fix ${error.filePath}. Relay refuses to start on an invalid policy, per FR-POL-2.`,
      }
    }
    throw error
  }
}

export async function checkPostgres(url: string): Promise<CheckResult> {
  const pool = createPool(url)
  try {
    await pool.query('SELECT 1')
    return { name: 'postgres', status: 'ok', detail: 'reachable' }
  } catch (error) {
    return {
      name: 'postgres',
      status: 'failed',
      detail: (error as Error).message,
      remediation: 'Run `docker compose up -d` and re-check.',
    }
  } finally {
    await closePool(pool)
  }
}

export async function checkRedisReachable(url: string): Promise<CheckResult> {
  const redis = createRedis(url)
  try {
    const alive = await pingRedis(redis)
    return alive
      ? { name: 'redis', status: 'ok', detail: 'reachable' }
      : {
          name: 'redis',
          status: 'failed',
          detail: 'ping failed',
          remediation: 'Run `docker compose up -d` and re-check.',
        }
  } finally {
    await closeRedis(redis)
  }
}
```

Create `src/doctor/run.ts`:

```typescript
import { loadRelayConfig } from '../config/load.js'
import { RELAY_VERSION } from '../version.js'
import {
  type CheckResult,
  checkConfig,
  checkNodeVersion,
  checkPostgres,
  checkRedisReachable,
} from './checks.js'

const SYMBOL: Record<CheckResult['status'], string> = {
  ok: 'ok',
  degraded: 'degraded',
  failed: 'FAILED',
}

/** Renders every result, including passes, so silence is never mistaken for health. */
export function formatResults(results: CheckResult[]): string {
  if (results.length === 0) return 'relay doctor: no checks ran'
  const lines = results.map((result) => {
    const base = `[${SYMBOL[result.status]}] ${result.name}: ${result.detail}`
    return result.remediation ? `${base}\n         fix: ${result.remediation}` : base
  })
  return [`relay doctor (relay ${RELAY_VERSION})`, ...lines].join('\n')
}

/**
 * Runs every check. Config is checked first because the connectivity checks
 * need its values, and a config failure short-circuits with an honest report
 * rather than pretending the remaining checks passed.
 */
export async function runDoctor(options: {
  configPath: string
  policyPath: string
}): Promise<{ results: CheckResult[]; exitCode: number }> {
  const results: CheckResult[] = [checkNodeVersion(process.version)]

  const configResult = checkConfig(options.configPath, options.policyPath)
  results.push(configResult)

  if (configResult.status === 'ok') {
    const config = loadRelayConfig(options.configPath)
    results.push(await checkPostgres(config.database.url))
    results.push(await checkRedisReachable(config.redis.url))
  } else {
    results.push({
      name: 'connectivity',
      status: 'degraded',
      detail: 'not attempted, because configuration is invalid',
    })
  }

  const exitCode = results.some((result) => result.status === 'failed') ? 1 : 0
  return { results, exitCode }
}
```
